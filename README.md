# Git and Login Testing Assignment


This submission demonstrates a local Git workflow with an initial commit, a follow-up change, a `feature` branch, a merge into `main`, ignore rules, and an undo operation using `git revert`.

## Files

- `index.html` and `about.html`: project pages
- `login_test_cases.md`: login-system test case table
- `git_commands.txt`: commands used, with brief explanations
- `.gitignore`: ignores `*.log` files and the `temp/` folder
